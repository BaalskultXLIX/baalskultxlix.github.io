Kurz: Sammlung von Befehlen und Beispielen. Passe Pfade und Geräte an deine Hardware an.

QEMU

Wozu ist das? QEMU ist ein Emulator/Virtualisierer, mit dem du ganze Rechner virtualisieren kannst. Hier werden typische Schritte beschrieben, um VMs mit UEFI-Unterstützung zu starten.

Installation (Arch Linux) — Erklärung: Der Befehl installiert das vollständige QEMU-Paket und die UEFI-Firmware (edk2-ovmf), damit du UEFI-VMs starten kannst.

sudo pacman -S qemu-full edk2-ovmf

Image erstellen — Erklärung: Mit qemu-img create legst du eine virtuelle Festplattendatei an. Das Beispiel erzeugt ein 4 GiB großes RAW-Image.

qemu-img create -f raw image_file 4G

Startkommando — Erklärung: Das folgende Beispiel startet eine x86_64-VM mit KVM-Beschleunigung, verwendet eine Q35-Maschine und bindet u.a. ein CD-ROM-Gerät. Passe Pfade wie /dev/sda oder Dateinamen an dein System an.

sudo qemu-system-x86_64 -enable-kvm -machine q35 -device intel-iommu -cpu host \
  -cdrom /dev/sda -boot order=d \
  -drive if=pflash,file=linux,format=raw \
  -netdev stream,id=s,server=off,addr.type=unix,addr.path=/tmp/passt_1.socket

Arch Linux Installation

Wozu ist das? Schritt-für-Schritt-Befehle, um Arch Linux auf einem Laufwerk zu installieren. Diese Liste fasst typische Kommandos zusammen; nutze stets die offizielle Installationsanleitung des Arch Wiki als Referenz.

Offizielle Anleitung: Arch Wiki — Installation guide

# Tastaturbelegung setzen (wichtig für Eingaben im Installer)
loadkeys de-latin1

# Anzeige aller Laufwerke (prüfe, welches Gerät /dev/sda ist)
fdisk -l

# Partitionierung (interaktiv mit fdisk)
fdisk /dev/sda

# FAT32 für EFI-Partition erstellen (EFI benötigt meistens FAT32)
mkfs.vfat -F 32 /dev/sda1

# Swap-Partition anlegen (Beispiel)
mkswap /dev/sda2

# Root-Partition als btrfs formatieren (Beispiel)
mkfs.btrfs /dev/sda3

# Swap aktivieren
swapon /dev/sda2

# Root partition einhängen
mount /dev/sda3 /mnt

# EFI-Partition erstellen und mounten (erforderlich für UEFI)
mount --mkdir /dev/sda1 /mnt/boot

# Basis-System installieren
pacstrap -K /mnt base linux linux-firmware

# fstab generieren
genfstab -U /mnt >> /mnt/etc/fstab

# In die neue Installation wechseln (chroot)
arch-chroot /mnt

# Einige zusätzliche Pakete installieren (z. B. Desktop, SDDM, Netzwerk)
pacman -Sy fish nano sudo networkmanager plasma sddm dolphin ark

Was machen die Pakete?

  • fish: Eine alternative Shell (Benutzerfreundlichere Shell).
  • networkmanager: Netzwerkverwaltung (für einfache WLAN/Netzwerk-Konfiguration).
  • plasma / sddm: KDE Plasma Desktop und Login-Manager.
  • dolphin: Dateimanager (für KDE).
